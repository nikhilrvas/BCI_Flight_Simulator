EEG Dataset Download Links

This folder contains EEG dataset links and documentation.

Dataset 2A (BCI Competition IV)
- Motor imagery of left/right hand, feet, and tongue
- [Download](http://www.bbci.de/competition/iv/#datasets)

Dataset IIIa (BCI Competition III) - This is what I have used. 
- Cued motor imagery: left hand, right hand, foot, tongue
- [Download](http://www.bbci.de/competition/iii/#dataset_IIIa)

Dataset V (BCI Competition III - IDIAP)
- Self-paced mental tasks (left hand, right hand, word generation)
- [Download](http://www.bbci.de/competition/iii/#dataset_V)
